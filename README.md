# Simple Calculator

This is a simple Odin calculator project assignment to test my knowledge and understanding of the DOM, DOM Manipulation and Event handling. You can have a [preview](https://xirlorm.github.io/odin-calculator/) to try it out.

## Technology used

- HTML
- CSS
- JavaScript

## Features

- Calculates the expression as you type them
- Modern and intuitive, easy to use UI
- Clear last character input or the whole expression

Simple calculations using:

- Addition
- Subtraction
- Multiplication
- Division
